Willkommen im Karussell-Cockpit

Vorschau ohne Installation. Sie läuft nur in diesem Browser-Tab, nichts wird hochgeladen, auch deine Fotos bleiben auf deinem Rechner.

Das Cockpit ist für den Computer gebaut. Am Handy siehst du nur einen Teil davon.

So probierst du es aus

  • Ein Element auf der Folie anklicken und ändern: Text, Farbe, Schrift, Größe. Doppelklick auf einen Text formatiert einzelne Wörter.
  • Neu legt ein Karussell aus einer der 15 Vorlagen an.
  • Serie baut viele Karussells auf einmal: gleiche Gestaltung, je Zeile neue Texte, wie die Massenerstellung in Canva.
  • Eigene Fotos einfach auf die Folie ziehen.
  • Vorschau oben rechts zeigt, wie es auf Instagram aussieht.

Nur in der Vollversion

Bilder, PDF und Canva-Datei ausgeben, Hintergrund entfernen, Videos, eigene Schriften und Logos, Wünsche an Claude. Das alles macht das Cockpit im SCB Creator Kit auf deinem Rechner.

Alles bleibt nur, solange dieser Tab offen ist. Neu laden oder schließen fängt von vorn an.
